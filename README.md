# Minimal Weather App

A lightweight, elegant Flutter application designed to fetch and display real-time weather information using RESTful API integration. Built with clean architecture and Material Design principles to ensure high UI responsiveness and smooth performance.

---

## 🌟 Key Features

* **Real-Time Weather Updates:** Fetches live temperature, weather conditions, humidity, and wind speed via OpenWeather API integration.

* **Dynamic Condition UI:** Adapts UI elements and condition-based visuals based on current weather reports.

* **Clean JSON Parsing:** Structured data modeling for efficient deserialization of complex API responses.

* **Error Handling & Resilience:** Gracefully manages network errors, invalid queries, and unstable connectivity to keep the UI interactive.

* **Offline-Friendly Caching:** Caches recent weather responses locally to optimize performance and reduce redundant network calls.



---

## 🛠️ Tech Stack & Architecture

* **Framework:** [Flutter](https://flutter.dev/) (Dart)
* 
* **API Service:** [OpenWeather REST API](https://openweathermap.org/api)

* **HTTP Client:** `http` package for asynchronous network requests

* **Design Guidelines:** Material Design 3
